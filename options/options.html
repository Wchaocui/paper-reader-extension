🤖 AI 模型配置

Key 只存储在本机 chrome.storage.local，仅在请求时直接发送给服务商。

💡 最省事的配置方式：点上面服务商的「Key 获取」链接 → 登录后复制 API Key → 回来点「从剪贴板一键导入」。智谱 Key 会自动识别服务商并填好全部字段；也可粘贴完整 JSON 配置（{"apiKey":"","baseUrl":"","model":""}）。

🧑‍🔬 我的研究者档案（用于精读「对我的启发」与审读第五类问题）

AI 审稿时会对照这份档案回答"这篇论文和我的研究在哪里能接上"。写得越具体，启发越贴合你的课题。

🌐 Google 在线表格同步（可选）

方式一（推荐，全自动）：部署一个 Google Apps Script Web App，把笔记一键写入 Google 表格。 打开 script.google.com， 按下方代码创建并部署为「任何人可访问」的 Web App，然后把 URL 粘贴到这里。

📋 查看 Apps Script 代码（点击复制使用） 
function doPost(e) {
  const body = JSON.parse(e.postData.contents);
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const name = body.sheetName || '文献笔记';
  const sheet = ss.getSheetByName(name) || ss.insertSheet(name);
  if (sheet.getLastRow() === 0 && body.header) {
    sheet.appendRow(body.header);
    sheet.getRange(1, 1, 1, body.header.length).setFontWeight('bold');
  }
  (body.rows || []).forEach(function (row) { sheet.appendRow(row); });
  return ContentService
    .createTextOutput(JSON.stringify({ ok: true, added: (body.rows || []).length }))
    .setMimeType(ContentService.MimeType.JSON);
}
